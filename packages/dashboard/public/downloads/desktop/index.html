Connect securely

    
Start Kala from your applications menu. Enter this Dashboard's origin, for example . Remote Hosts require HTTPS; HTTP is accepted only for explicit loopback such as http://127.0.0.1:13000.

    
Sign in inside the desktop client; browser cookies are not imported. Workspace paths and terminals remain on the remote Runtime. The client has no shell or filesystem API exposed to Dashboard scripts. A working network connection is required.

    
Normal package updates through APT

    
A production signed APT repository has not been configured for this build. Do not add an unsigned repository or use trusted=yes. Once an operator publishes a signed HTTPS repository and verifies its signing-key fingerprint independently, your regular apt update / apt upgrade workflow can update the client.

Supported systems

    
Ubuntu 24.04 amd64 or compatible systems with GTK 3 and WebKitGTK 4.1. Debian/older Ubuntu compatibility must be verified against the package's minimum libc dependency. No Windows, macOS, Snap or AppImage package is advertised.
