# Historical documentation

This area keeps completed implementation programs, previous reviews, and incident records for traceability. These files are **not** current installation steps, acceptance evidence, or product contracts. Start at the [documentation index](../README.md) to find the current authoritative document before acting on a historical finding.

- [Programs](programs/) — completed or superseded implementation ledgers.
- [Reviews](reviews/) — point-in-time findings and design reviews.
- [Incidents](incidents/) — historical investigation records.

Some historical documents retain original paths because code or tests refer to them. Revision-bound [evidence](../evidence/README.md) retains its original path and its own authority rules.
