# Guides

Start with the [Kala overview](../../README.md) for the product, its releases, and the primary workflow. Guides explain *what to do*; use [operations](../operations/README.md) for version-specific installation, backup, upgrades, and recovery.

## Choose a deployment

| Option | When to choose it | Continue with |
| --- | --- | --- |
| Portable | One user-managed Host distributed as a CJS or native binary | [Release and installation overview](../../README.md#releases) |
| Dedicated | A complete, single-tenant Platform with a stable ingress and deploy supervisor | [Dedicated operator guide](../operations/dedicated-operator-cli.md) |
| Private Cloud | A multi-tenant Platform with isolated runtime units | [Private Cloud first install](../operations/private-cloud-first-install.md) |

See the [deployment mode contract](../architecture/deployment-mode-contract.md) for the authoritative boundaries. A deployment's available capabilities and release assets must be verified before following any platform-specific instructions.
