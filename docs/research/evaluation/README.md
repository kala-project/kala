# Domain Knowledge

This directory stores externally sourced domain notes that affect product, protocol, and evaluation design.

The standard for this directory is stricter than normal project notes:

- Key claims must cite primary or authoritative sources.
- Source links should be pinned when the source is code.
- Product recommendations must distinguish benchmark semantics from agent-kernel implementation choices.

## Documents

- [SWE-bench Evaluation](swe-bench-evaluation.md): end-to-end SWE-bench evaluation flow, official harness behavior, scoring semantics, and product implications for agent-kernel.
- [Terminal-Bench Evaluation](terminal-bench-evaluation.md): terminal-agent task model, sandbox execution, test parsing, and product implications.
- [WebArena Evaluation](webarena-evaluation.md): web-agent environment setup, config/evaluator model, score semantics, and browser-trace product implications.
- [Tau-Bench / Tau3-Bench Evaluation](tau-bench-evaluation.md): general tool/user-interaction benchmark model, reward basis semantics, and product implications.
